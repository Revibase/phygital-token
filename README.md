# phygital-token

Binds Revi NFC cards to Solana tokens.

- [`programs/phygital-token`](programs/phygital-token): the Solana program
- [`packages/js/phygital-token`](packages/js/phygital-token): `phygital-token-sdk`, which signs payloads with a card
- [`app`](app): Revibase, the tap-to-claim web app

Report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md). MIT licensed.
